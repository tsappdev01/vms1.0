## What is not in here

- **The entity list itself.** `vms.Entity` is reference data maintained by script in
  `db/`, not seeded from code, so that the group's companies can change without a
  rebuild. Its rows are not part of the schema.
- **Audit tables.** There are none. Visits cannot be edited or deleted through the
  application, so the row is its own record; see `09-access-control-matrix.md`.
- **Retention.** Nothing deletes a visit. See `08-data-classification.md`.
